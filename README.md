# NEXUS Portfolio

A responsive personal portfolio website showcasing my design work and JARVIS OMEGA visual concept.

## Features

- Futuristic black-and-neon-green visual theme
- Responsive page layout
- Home, Projects, and About navigation
- JARVIS OMEGA poster showcase
- JavaScript-powered footer year and navigation interactions

## Technologies

- HTML
- CSS
- JavaScript

## Run locally

Download or clone this repository, then open `index.html` in a web browser.

## Project status

This is a learning project built to practise front-end development, responsive design, and interactive website features.
